Personal Backup

Privacy Policy

Effective November 18, 2026.

This policy describes the intended operation of Personal Backup, a private, owner-operated desktop backup application, and its public information site.

Data and permissions

The application is intended to request the Google Drive drive.file scope. It uses authorized access to create and manage backup files and folders, read their contents and metadata, verify backups and restore files. The owner chooses the local files to back up. Organization-owned records are outside the scope of the personal backup.

Use, storage and protection

Selected data is encrypted locally by restic before upload to the owner's Google Drive. Backup objects are stored in that account. OAuth credentials and backup passwords are handled on the owner's computer or in the owner's credential manager, not on this website. Authorized Google user data is used only to provide the backup and restoration functions described above. It is not sold, used for advertising, or intentionally shared with other users. Google Drive acts as the storage provider.

Retention, deletion and revocation

The owner controls the backup repository and its retention settings, and may delete backup data from Google Drive or revoke application access through Google Account connections. Revoking access does not itself delete previously stored backup files.

Website

This static information site contains no application login, analytics script, tracking script, or upload form. GitHub Pages hosts it and may process ordinary web request information under the GitHub Privacy Statement.

Contact

For questions about this policy, use the public issue tracker. Do not submit private data, backup contents, passwords or tokens in public issues.

Google API data handling is subject to the Google API Services User Data Policy, including its applicable Limited Use requirements.
